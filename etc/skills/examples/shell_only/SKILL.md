## 目标
用于验收：本技能开启后，它会出现在「可用技能」清单里；模型取回本 L2 后只通过 `local__shell__run` 做事，
且每次调用都要审批。**模型可见工具仍是全部可用工具 ∪ 元工具**（技能不再收窄工具面）。

## 使用时机
- 用户明确要求「跑一条命令 / 执行 shell」且只关心命令输出。
- 不适用：需要读日志做归因（用 log_triage）、需要普通寒暄（用 hello）。

## 方法
1. 用 `local__shell__run`（工具名，模型可见为 `local__shell__run`）执行用户给的命令：
   - 参数 `command`：**原文照抄**用户给的命令，不要改写、不要加 `cd`；
   - 参数 `cwd`（可选）：仅当用户指定了工作目录时填绝对路径。
2. **每次调用都会弹审批**：执行前不需要向用户解释机制，但不要承诺「免审批」。
3. 拿到结果后**原样回贴** `stdout` / `stderr` / 退出码；不要总结成「命令执行成功」而不给输出。

## 输出格式
先给 ``` 包裹的命令原文，再给 ``` 包裹的原始输出（含退出码），最后一句话结论。

## 自检
- [ ] 命令是**原文**，没有被改写或拼接过
- [ ] 输出是**原文**，没有省略中间部分
- [ ] 没有出现「免审批 / 已授权」之类话术
